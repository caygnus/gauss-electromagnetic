# Gauss Electromagnetics - Corporate Website

A modern, SEO-optimized corporate website for Gauss Electromagnetics, a leading manufacturer of high-precision electrical equipment including reactors, transformers, VFD chokes, and harmonic filter reactors.

## 🚀 Features

- **SEO Optimized**: Comprehensive SEO implementation with dynamic metadata, OpenGraph, Twitter Cards, and structured data (JSON-LD)
- **Automated Sitemap**: Automatic sitemap generation with `next-sitemap`
- **Structured Data**: Schema.org markup for Organization, Products, Breadcrumbs, and more
- **Responsive Design**: Modern, mobile-first design with Tailwind CSS
- **Type-Safe**: Full TypeScript implementation
- **Performance**: Optimized with Next.js 16 App Router

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org) with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **UI Components**: Radix UI primitives
- **SEO**: Custom SEO utilities + `next-sitemap`
- **Email**: Resend for contact forms
- **Deployment**: Vercel

## 🔍 SEO Implementation

### Features

- **Dynamic Metadata**: Page-specific metadata with OpenGraph and Twitter Cards
- **Structured Data**: JSON-LD schemas for Organization, Products, Breadcrumbs, WebSite
- **Automated Sitemap**: Generated automatically on build with `next-sitemap`
- **Robots.txt**: Auto-generated with proper crawl directives
- **Canonical URLs**: Automatic canonical URL generation
- **Breadcrumbs**: Schema.org BreadcrumbList on all pages

### Sitemap Configuration

Pages can control sitemap inclusion by exporting `sitemapConfig`:

```typescript
export const sitemapConfig = {
    include: true,
    priority: 0.9,
    changefreq: "monthly",
} as const
```

### SEO Utilities

Located in `src/lib/seo/`:

- `metadata.ts` - Metadata generation helpers
- `structured-data.ts` - JSON-LD schema generators
- `sitemap-decorator.ts` - Sitemap configuration helpers
- `automation.ts` - SEO validation and automation

## 📧 Contact Form

The contact form uses Resend for email delivery. Configure in `config.yaml` or environment variables:

- `RESEND_API_KEY` - Your Resend API key
- `RESEND_FROM_ADDRESS` - Verified sender email
- `ADMIN_EMAIL` - Email to receive enquiries

## 🚢 Deployment

### Vercel Deployment

The project is configured for automatic deployment to Vercel via GitHub Actions.

**Required GitHub Secrets:**

- `VERCEL_TOKEN` - Vercel API token (from team owner account)
- `VERCEL_ORG_ID` - Vercel organization/team ID
- `VERCEL_PROJECT_ID` - Vercel project ID

**Deployment Process:**

1. Push to `main` branch
2. GitHub Actions builds and generates sitemap
3. Deploys to Vercel production

### Environment Variables

Set these in Vercel dashboard or `.env.local`:

**Client-side (NEXT*PUBLIC*\*):**

- `NEXT_PUBLIC_SITE_URL` - Production site URL

**Server-side:**

- `RESEND_API_KEY` - Resend email service key
- `RESEND_FROM_ADDRESS` - Sender email address
- `ADMIN_EMAIL` - Admin notification email

### Adding New Pages

1. Create page in `src/app/(home)/`
2. Export metadata with `generateMetadata()` helper
3. Export `sitemapConfig` for sitemap inclusion
4. Add structured data (breadcrumbs, etc.) as needed

Example:

```typescript
import { generateMetadata as genMetadata } from "@/lib/seo"
import { mediumPrioritySitemapConfig } from "@/lib/seo"

export const metadata = genMetadata({
    title: "Page Title",
    description: "Page description",
    path: "/page-path",
})

export const sitemapConfig = mediumPrioritySitemapConfig("monthly")
```
